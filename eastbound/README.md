# EASTBOUND

面向外国人的「旅游中国」英文站（团队内部用中文沟通）。

## 本地运行

```bash
cd eastbound
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

## 已实现（MVP）

- 首页英雄区 + 城市入口
- `/plan` 行前清单
- `/destinations` 与北京 / 上海 / 西安 / 成都指南
- `/itineraries/classic-10` 十日经典线
- `/transport`、`/essentials` 实用页

## 技术

Next.js（App Router）· TypeScript · Tailwind CSS v4

站点对客文案为 **English**；本 README 与协作说明用中文。
